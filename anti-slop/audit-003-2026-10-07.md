# antislop audit 003 (2026-10-07), Git repository browser

Scope: `apps/web/src/pages/tenant/GitBrowse.tsx`, the clickable card in `TenantGitAccounts.tsx`, read-only endpoints in `apps/agent/src/routes/admin/gitAccounts.ts`, `browse*` in `packages/skills/src/git.ts`.
Not verified in a browser: everything below comes from reading the code. Contrast was not computed.
Code comments: none added that restate code; nothing to remove.

1. MEDIUM (R-32, keyboard): the repo tabs use `role="tab"` / `aria-selected` but have no `aria-controls`, no `role="tabpanel"`, and no arrow-key movement, so they announce as a tab widget without behaving like one. Fix: reuse `components/ui/tabs.tsx` (Radix) or drop the roles and use plain buttons with `aria-pressed`.
2. MEDIUM (R-35, tap targets): the "Open on provider" icon link is a bare 16px icon with no padding, and the tab buttons are about 32px tall. Fix: pad the icon link to 44 x 44 and raise the tab height on narrow widths.
3. LOW (R-27, perceivable states): rows appended by "Load more" are not announced, and the button only changes its label to "Loading". Fix: an `aria-live="polite"` count ("30 loaded") next to the button.
4. LOW (R-25, unverified): metadata text is `text-xs text-muted-foreground` on `hover:bg-muted/40` cards; contrast was not computed. Same open item as audit 002 #4. Fix: run the contrast checker on the two tokens in `index.css`.
5. LOW (R-35, unverified): the repo grid (`sm:grid-cols-2 xl:grid-cols-3`) and the long-title rows were not checked at phone width; long labels and `source → target` strings may wrap badly. Fix: check at 360px, add `break-words` where needed.
6. LOW (behavior, not antislop): repositories are grouped by owner only among the pages already loaded, so an owner can appear with a partial list until later pages are loaded. The filter says so, the grouping does not. Fix: show "N loaded" in the page header, or accept as a known limit.
7. LOW (behavior, not antislop): GitHub "Members" falls back to contributors when the token cannot list collaborators, labelled `contributor`. A reader may take that for the full member list. Fix: show a one-line note under the list when the fallback was used.

## Status
All 7 closed on 2026-10-07.
1. Tabs now use `components/ui/tabs.tsx` (Radix): arrow keys, `aria-controls`, `tabpanel`.
2. Open-on-provider link is 44 x 44 (`size-11`); tab buttons are `min-h-11` below `sm`.
3. "N loaded" line under each list, `aria-live="polite"`, also says "all shown" when done.
4. Computed with `contrast-check.py`: muted text `#737373` on white 4.74:1 PASS, on `#fafafa` 4.54:1 PASS, dark `#a3a3a3` on `#171717` 6.94:1 PASS, inactive tab (foreground at 60%) on white 5.25:1 PASS. One failing pairing exists: `#737373` on `#f5f5f5` is 4.35:1. It happens only on hover in `CopyId.tsx` (muted text on `hover:bg-muted`), a component older than this work. `hover:text-foreground` already replaces the text color in that state (`#0a0a0a` on `#f5f5f5` passes), so the failing pairing never shows. The other `bg-muted` uses hold foreground text or icons only. No change needed.
5. Checked in headless Chrome at 360, 768 and 1280 px with a long-title fixture: no horizontal page scroll on any of the five views. It found one real overflow, the tenant tab bar (`TenantDetail.tsx`, 2px at 360px); fixed with `overflow-x-auto` and `whitespace-nowrap`. Long titles, branch names and usernames wrap (`break-words` / `break-all`).
6. A one-line note above the groups, shown while more pages exist: groups list only what is loaded.
7. The members endpoint now returns `contributorsOnly`, and the tab shows a note when GitHub refused the collaborators list.
